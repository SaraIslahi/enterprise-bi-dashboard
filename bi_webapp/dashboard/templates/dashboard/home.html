Upload Dataset View Dashboard

What this app does

Transforms raw CSV data into KPIs and analytical charts.

How data is handled

Uploads are loaded into a staging table without affecting the core warehouse.

Designed for BI

Follows dimensional modeling principles (facts & dimensions).

How it works

1
Upload a CSV file

Provide a sales dataset using the upload page.

2
Data is staged in the database

Your dataset is validated and loaded into a staging table.

3
KPIs & charts are generated

The dashboard queries the data and renders insights.

Key features

KPI Summary

Total revenue, number of orders, and average order value.

Revenue by Country

Compare geographic performance using aggregated charts.

Revenue Over Time

Analyze trends with time-series visualizations.

Supported data

This application is designed for sales order datasets. Extra columns are ignored. Future versions support column mapping for flexible schemas.

Recommended fields: order_id, order_date, customer_name, country, product_name, quantity, revenue
